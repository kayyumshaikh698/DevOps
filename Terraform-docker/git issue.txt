To configure Git to stop trying to run automatic background cleanups (which triggers the OneDrive file-locking error), make sure you are in your main project folder (C:\Users\kayyu\OneDrive\Desktop\GIT\Terraform-docker) and run this command:
# disabling git auto cleanup
git config --local gc.auto 0  
# manually cleanup git 
git gc --prune=now
# enabling git auto cleanup 
git config --unset gc.auto
